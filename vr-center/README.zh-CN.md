## VR-CENTR 与 Astra HD：配合安装和使用

### 开发目标

我们希望让Cyberpunk 2077成为完整的VR体验：从空间菜单和角色编辑器，到舒适易读的HUD及与游戏世界的交互。基础是优质立体画面、稳定帧率，以及神经渲染与帧生成的协调工作。界面应适合头显和VR控制器。这是开发目标，不是已经完成的功能清单。

这是一套尚未完成的实验性组合，不是已经完成的稳定 VR 移植。Astra HD 将游戏画面送入头显，VR-CENTR 管理安装内容和配置档。之所以开发配置档，是因为反复测试 VR、模组和图形库后，曾留下混杂且无法工作的文件组合。它们用于重复测试并恢复选定状态，避免每次测试后手动删除多个游戏目录、通过 Steam 重新下载或重装。

**目前尚无可直接安装的组合压缩包。** [Astra HD Releases](https://github.com/konstanaft-stack/Astra-HD/releases) 是今后的下载位置。自动生成的 Source ZIP 只是源代码，不是安装程序；仅克隆源码不能恢复可用安装。

经过验证的安装包发布后，请按以下顺序操作：

1. 通过 Steam 安装您拥有的 Cyberpunk 2077。公开安装包不包含游戏本体、付费第三方移植或个人存档。
2. 从 Releases 下载已准备好的安装包，解压，运行包内安装程序并选择自己的游戏目录。
3. 在 VR-CENTR 中先保存经过验证的干净基线，创建干净配置档，再选择模组集合和 Astra HD VR 移植，应用该组合。
4. 从管理中心启动游戏。关闭游戏后才能切换配置档、移植或图形库；先保存需要保留的当前状态。

共享的 OptiScaler/NR/MFG 每套游戏只安装一份，不是每个配置档一份。请单独备份个人存档。HUD、编辑器、运动效果和性能仍需在头显中验证。


### 当前实验与开发方向

- **双摄像机：**独立左右视角是当前基础。帧率、帧生成和稳定性仍在调试，尚未验证80 FPS目标。
- **交替双眼/AER：**用户主观感觉它比当前双摄像机模式更自然、更自由、更有临场感；原因尚不明确。该模式远未完成：巨大光晕曾减轻或消失，后来又出现，回归问题尚未解决。
- **立体角色编辑器：**正在开发空间预览、头显观察，以及左手grip/stick调节摄像机高度和缩放。居中、UI重叠和帧率缺陷仍存在，不能称为已经验收的完整Luke式模式。

欢迎针对具体缺陷或分支开展研究并提交PR。请提供版本、GPU、HMD/runtime和复现步骤。保留上游作者署名。

### 当前原型操作：编辑器摄像机

按住左手grip：左摇杆↑↓调节高度（0.5米/秒），←→调节距离（0.6米/秒）。Grip+按下左摇杆仅重置摄像机高度/距离，不是全局头显重新居中。鼠标：Shift+滚轮调高度，Ctrl+滚轮调距离，Ctrl+中键重置。轴向操作仍需头显验证。

OptiScaler：Insert打开菜单，F12请求切换其FG，\在进入世界后切换NR；与移植自身的Own FG不同。当前RTX4060配置的NR310.9.16仍返回createFeatureNotSupported。

欢迎创建分支、将我们的改动移植到其他分支或为主项目加入Cyberpunk支持，也欢迎协助解决具体缺陷。我们仍会继续自己的开发；请保留许可证和上游署名。

# VR-CENTR

[![English](https://img.shields.io/badge/English-read-384b69)](README.md) [![Русский](https://img.shields.io/badge/Русский-читать-384b69)](README.ru.md) [![简体中文](https://img.shields.io/badge/简体中文-当前-2d8659)](README.zh-CN.md)

**项目仍在开发中。** VR-CENTR 是一款 Windows 桌面工具，用于管理用户自己通过 Steam 安装的 **《赛博朋克 2077》**。目前的代码只针对这款游戏；其他 Steam 游戏需要今后单独开发适配器，**现在尚不支持**。公开源码是为了方便社区审阅和参与，界面与工作流程仍需完善。

![VR-CENTR 头显图标](Assets/vr-center-quest3-cyberpunk.png)

## 目前代码具备的功能

- 根据**事先保存并验证过的纯净基线**创建新的游戏配置档。程序会核对本地清单和文件哈希；仓库既不提供游戏，也无法凭空补齐缺失的基线文件。
- 保存、切换完整的《赛博朋克 2077》配置档，并用事务日志辅助检查和恢复。切换时可能需要读取和复制大量文件，因此速度可能较慢，也需要足够的磁盘空间；请勿中途强行终止。
- 列出已安装或从本地导入的 VR 移植版本，选择可选组件和 NVIDIA 库，并在应用配置前检查和备份文件。导入 ZIP 只表示加入候选列表，不代表兼容性或头显画质已通过验证。
- 使用已配置的 Mod Organizer 2 配置档启动游戏；检测 Vortex，并可隔离《赛博朋克 2077》已知模组目录中的附加文件。程序**不会**切换 Vortex 的 LevelDB 配置档，也不会代替用户执行 Deploy/Purge。
- 启动前检查和状态显示。VR 移植、帧生成、画质和舒适度仍需在真实头显中验证。

## 在 Windows 上构建与运行

先安装 .NET 8 SDK 和 PowerShell 7（`pwsh`）。克隆仓库，把 `config.example.json` 复制为 `config.json`，再把路径改成**你自己的** Steam 游戏安装目录和另行取得的《赛博朋克 2077》VR 组件目录。Git 会忽略 `config.json`。VR 组件必须包含后端所需的清单和安装脚本，本仓库不提供这些文件。创建纯净配置档还需要事先保存并验证的纯净基线。MO2 和 Vortex 如需使用，也要自行安装和配置。

```powershell
Copy-Item .\config.example.json .\config.json
dotnet restore .\VRPorts.csproj
dotnet run --project .\VRPorts.csproj
# 在被 Git 忽略的 releases/ 目录生成独立 Windows 版本：
.\Build.ps1 -Version local
```

随仓库提供的 Quest 3 图标是为本项目生成的。公开源码使用重新编写的简洁 Avalonia 主题，因此外观与私人工作版本可能不同。仓库不包含私人配置、已保存的配置档、模组、游戏文件、VR 移植二进制文件或发行版程序。

**备份范围：** 从 GitHub 克隆本仓库可以找回应用源码、构建脚本和示例配置，却无法恢复游戏许可与安装、VR 组件、模组合集、MO2/Vortex 数据、个人配置档、设置、存档以及已验证的纯净基线。这些内容需要在遵守各自授权条款的前提下另行备份。
