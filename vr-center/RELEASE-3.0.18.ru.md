# VR-центр 3.0.18 — Astra HD

Карточка нашего VR-порта и текущая сборка теперь называются **Astra HD**. Оригинальный ToFu остаётся отдельной карточкой. Названия семи наших сохранённых вариантов приведены к Astra HD; различающие даты/пометки старых вариантов сохранены.

Текущая сборка по умолчанию: внутренний ID tofu-aer-v1-candidate, DLL C2408835C7944FEA0D1766BB1458415A9627F1193241B5A569C2D884EB148F05. Внутренние ID и состав файлов не менялись, поэтому сохранённые настройки и выбор текущей сборки сохраняются. Кнопка проверки GitHub и горячие клавиши имеют прежнее поведение.

Возврат: закрыть игру и Vortex → VR-центр → Cyberpunk 2077 → Astra HD → Применить → Запустить. Если Astra HD уже установлена и изменений нет, достаточно Запустить. Смена карточки сама по себе ничего не устанавливает.

Исправлена сборка приложения: диагностические C# файлы audit/tests и опубликованные releases исключены из автоматического набора Compile. Без этого старый lifecycle-fixture.cs добавлял вторую точку входа (CS0017).

Проверено: publish win-x64 успешен; две предупреждающие записи CS9057 об анализаторах Avalonia не блокируют сборку. Read-only preflight Astra HD проверил 502 элемента пакета и настройки. Метаданные изменены только в полях label/family; карты payload совпадают. VR-центр 3.0.18 запущен, ярлык обновлён. Установленный в игре Ajson V47 не переключался.

Штатный инструмент карантина в режиме WhatIf отверг apps/VR-Ports/releases как путь вне своего allowlist. Старая 3.0.17 оставлена неактивной; обход ограничений и ручной перенос не выполнялись. Это ограничение инструмента очистки, не незавершённое переименование.
