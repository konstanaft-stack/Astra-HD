# Обновления, 09.10.2026

Кнопки «Обновления» в верхней навигации и «Обновления GitHub» в расширенном режиме. Окно: проверить GitHub, выбрать репозиторий/релиз/файл, скачать, добавить скачанный выпуск в библиотеку. Используются существующие функции Update-Ports.ps1 и Import-Port.ps1, а не новый несовместимый установщик. Само скачивание/импорт не меняет игру.

Живой проверкой получено: upstream0.1.7, ToFu v0.1.7-TE6-ported, Ajson v0.1.7-ajson-v47, iPower Version.0.1.7-beta3. Через новый backend Ajson v47 реально скачан и импортирован; размер и SHA256 совпали с метаданными GitHub. Следующий выбор версии Ajson включает v47. Игра не запускалась/не устанавливалась.

Причина отсутствия кнопки в v2.0 — старый обновлятор не был подключён к новому frontend. Теперь подключён. Последняя публикация releases/2.1, основной ярлык перенаправлен туда; уже открытое окно2.0 требуется закрыть и открыть вновь.

Причина отсутствия свежей RR — Get-LibraryCatalog показывал только файлы из старых локальных сборок. Добавлен отдельный расширяемый library-catalog.json. «Обновить каталог NVIDIA» получает latest release NVIDIA/DLSS, читает rel DLLs, проверяет размер и Git blob SHA1 из официального contents API, сохраняет SHA256 и реальную PE-версию. Уже имеющиеся совпадающие объекты не скачиваются повторно. На проверке SR,FG,RR имеют310.9.1.0. RR SHA256=4BC7EA5FCB2F32CF86BC2CB072E8D2860914A0BE511CBDCB2FC206C1D9D83B80. В игре сохранилась прежняя RR, обновлён только выбор библиотеки.

Доказательства: tests/{updates,download,import-update,nvidia}-result.json; data/updates/ports.json; data/library-catalog.json; build-v21.log. Компиляция успешна; новое окно ещё не осмотрено живьём, поскольку пользователь использует открытый предыдущий экземпляр. Старое предупреждение CS9057 анализаторов сохранено.
