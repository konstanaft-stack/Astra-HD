# VR-центр 3.0.8 — компактные переключатели

Прямое уточнение пользователя 10.10.2026: сохранить название Vortex, маленькая цветная плашка по ширине надписи, отдельный переключатель справа, зелёный=включено и красный=выключено. Выключенный Vortex означает чистый состав выбранного порта с обязательными зависимостями, без дополнительных модов. Не добавлять отдельную кнопку профиля и постоянные пояснения.

Реализовано: компактные плашки компонентов с отдельными ToggleSwitch, красной/зелёной заливкой; компактные строки выбора версий DLL; простой экран уменьшен до365px, расширенный до620px. Vortex применяется сразу отдельным SetMods, не требует полного снимка/переустановки порта или нажатия общей кнопки Применить. Остальные компоненты сохраняют существующий механизм применения.

Сохранённый mods-state.enabled — единственный выбор пользователя, по умолчанию false. Найденные внешние файлы больше не включают настройку. При Launch выключенный профиль повторно убирает внешние файлы, если их вернул внешний менеджер; обязательные файлы receipt и runtime внутри принадлежащих порту CET/RED4ext модулей сохраняются. Старые припаркованные runtime-настройки не восстанавливаются поверх текущих.

Проверено:
- mod-profile.tests.ps1: default off, сохранение on/off, повторный внешний deploy не меняет выбор, чистый запуск сохраняет зависимость, включение возвращает сторонний файл.
- managed-runtime.tests.ps1: собственные runtime DB/INI не считаются сторонними модами.
- components.tests.ps1: dependency retention, restore/conflict/receipt/library/hold/import проверки.
- publish успешен; остаётся предупреждение версии Avalonia analyzer/компилятора CS9057.
- В реальном окне переключатель Vortex дал зелёную плашку и enabled=true; выключение дало enabled=false. После закрытия/повторного открытия UI плашка красная, выбор сохранён. Сторонних файлов/припаркованных файлов0, игра не запускалась.
- Start-Game -CheckOnly PASS для tofu-aer-v1-candidate после изменения. Ярлык VR-центр указывает releases/3.0.8/VRPorts.exe, новая версия открыта.

Evidence/backups: audit/compact-controls-20261010, включая снимки зелёного состояния, красного после перезапуска и расширенного вида. Резерв старого ярлыка и исходников рядом; пользовательские файлы/архивы модов не удалены. Эти проверки не означают исправления игровых камер, меню, настроек игры или взаимодействий.
