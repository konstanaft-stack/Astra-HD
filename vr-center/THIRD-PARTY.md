# Third-party boundaries

VR-CENTR uses Avalonia 12.1.0, Avalonia.Desktop, Avalonia.Themes.Fluent and Avalonia.Fonts.Inter through NuGet. Their package licenses apply to restored packages and distributed binaries. Before publishing a binary release, include the NuGet package notices and licenses generated for that build.

The private predecessor's appearance referenced [NODIX-TECH/DLSS-5-MANAGER](https://github.com/NODIX-TECH/DLSS-5-MANAGER), snapshot `92a80e179bb2aff28763d05bec3c50186ab94ca9`. Its copied `App.axaml` styles and background images are excluded from this repository and from the clean build. The `App.axaml` here is an independently written compact theme. No NODIX-TECH source license is asserted.

The included Quest 3 icon was generated for VR-CENTR. Cyberpunk 2077 and Steam are trademarks of their owners. The application does not include game files, saves, VR-port implementations, OptiScaler, NVIDIA libraries, mods, MO2, Vortex, or a prepared clean baseline. Separate components obtained by the user remain under their own terms.

The MIT license in this repository covers only code, documentation and artwork that VR-CENTR contributors have the right to license. It does not relicense external software or assets.
