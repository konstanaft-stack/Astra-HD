# VR-центр — экспериментальный portable runtime для Windows x64

Этот архив содержит скомпилированный VR-центр с публичной темой, self-contained .NET runtime, VfsHost и usvfs. Центр управляет выбранным составом Astra HD, библиотеками и профилями Cyberpunk 2077. Профили помогают возвращать проверенное состояние после экспериментов без ручной очистки папок и повторной загрузки игры.

**Это VR-центр для экспериментальной пары с Astra HD r29 native-base.** Сам порт распаковывается из отдельного архива. Игра, коллекции модов, личные настройки/сохранения и чистая основа игры сюда не входят. В первой native-base поставке есть VR и выбранные NVIDIA SR/RR/G; optional OptiScaler/NR/MFG не включён и не объявляется готовым. Совместная работа NR+FG — отдельный следующий этап.

## Первый запуск

1. Нужны Windows x64, установленная вами Steam Cyberpunk 2077 и **PowerShell 7 (`pwsh`) в PATH** — [официальная установка для Windows](https://learn.microsoft.com/powershell/scripting/install/installing-powershell-on-windows). .NET SDK для этого скомпилированного архива не нужен.
2. Распакуйте всю папку `VR-CENTR` в новый каталог, доступный для записи. Не копируйте только `VRPorts.exe`: рядом нужны DLL, scripts, `helpers`, `components`, `integrations` и notices.
3. Отдельно распакуйте выбранный совместимый Astra runtime bundle. В нём должны быть `bundle.json` и `stock-paths.json`; готовый порт здесь не подменён Source ZIP.
4. Запустите `Start-VR-CENTR.cmd`. При первом запуске укажите папку своей игры, если она не обнаружена, затем папку распакованного Astra bundle. Wrapper создаст частный `config.json` на этом ПК и запустит центр. Готовый `config.json` с другого компьютера не копируйте.
5. Если в выбранном bundle есть `shared-package.json`, wrapper проверит schema1, `game-shared` и `off-until-manual`, затем свяжет его с локальной конфигурацией. Относительные CAS-источники разрешаются относительно самого definition-файла. Отсутствующий optional shared definition сохраняет прежнее поведение без него; неизвестный формат не принимается молча.

Из PowerShell в распакованной папке выполните:

```powershell
.\Start-VR-CENTR.cmd
```

Путь bundle вводится в появившийся запрос `Full path to your separately obtained Cyberpunk VR bundle`, например `D:\Games\Astra-HD-Portable` — это папка с `bundle.json`, не сам ZIP. У wrapper нет отдельного CLI-параметра `-BundleDirectory`. Если игра находится в нестандартной Steam library и обычная папка Steam не обнаружена, в запрос `Full path to your Steam Cyberpunk 2077 directory` введите её полный путь, например `E:\SteamLibrary\steamapps\common\Cyberpunk 2077`. Пробелы в этих ответах поддерживаются. Уже созданный частный config сохраняется при следующем запуске.

Общий NR/MFG-комплект устанавливается/проверяется штатным действием центра и имеет отдельную запись состояния. Наличие manifest само по себе не означает уже установленный общий комплект. После установки matching shared package политика запуска удерживает NR выключенным до ручного включения; остальные пользовательские значения и горячие клавиши сохраняются.

### Обязательный порядок на новом ПК: чистая основа → профили → VR

До первой установки VR запустите **чистую игру без модов** до главного меню и выйдите. В центре нажмите **«Сохранить чистую основу»** и подтвердите фактический первый запуск и выход. Снимок сохраняет исходные файлы, AppData и Saved Games; изменённую сборку нельзя выдавать за чистую. Не устанавливайте порт до этого снимка: Native Apply не создаёт его автоматически.

Через **«+»** создайте профиль, например **«Flat»**, и сохраните его как путь возврата к исходной игре. Затем создайте отдельный профиль **«VR»**, выберите в нём **Astra HD r29** и примените порт. Для возврата выбирайте сохранённый **профиль Flat**. Переключение профилей восстанавливает его исходные stock DLL, настройки и сохранения через проверенный снимок.

Прямой flat-пункт установки у минимального bundle недоступен: пустой `flat.files` не содержит stock DLL для обычного installer fallback. Не используйте его как замену переключению на сохранённый Flat-профиль. Если чистой основы нет или штатные файлы недоступны, остановитесь на сообщённой ошибке; не удаляйте библиотеки вручную. Все установки и переключения выполняйте при закрытой игре и менеджерах модов. Личные сохранения переносите отдельно.

## Что проверено у этого кандидата

Сохранены бинарные файлы проверенного public runtime02; center04 меняет только PowerShell workflow и инструкции. VR-template выбирает доступную native-версию из `bundle.defaultVersion`, включая R29; прежний ToFu fallback работает только при его действительном наличии. CPU fixture проверяет clean capture → R29 VR-профиль → возврат к captured Flat. Ранее прошли15 NR policy и17 production headless UI проверок; bootstrap/relative-CAS имеет отдельные21 readback checks. GUI, игра и перенос на другой физический ПК в этом проходе не запускались.

Исходники центра подготовлены для `vr-center/` в том же Astra-HD repository. Установочных архивов/релиза в этом рабочем проходе не публиковали. Точные dependency notices и метаданные находятся в `licenses/`; исторические source-only инструкции сохранены отдельно в `docs/source-backup/`.

usvfs распространяется под GPL-3.0-or-later; его полный текст и известные upstream/source сведения приложены. Соответствие точного corresponding source для включённых0.5.6.1 binaries остаётся пунктом финального publication review; этот audit-кандидат не выдаётся за завершённую публичную поставку.
