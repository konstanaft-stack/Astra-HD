# VR-центр 3.0.15 — однозначные режимы

Прямое требование пользователя: название плашки показывает действующий режим, а не название выключенной альтернативы. Компактная плашка и отдельный переключатель остаются.

- «Настройки игры» ↔ «Рекомендуемые настройки».
- «Чистый профиль» ↔ «Vortex».
- Оба варианта режима рабочие, поэтому их плашки зелёные. Красный/зелёный остаётся у самостоятельных дополнений: выключено/включено. Цвет дополнения отражает применённое состояние, а не ещё не применённый выбор.
- Недоступные для выбранного порта OptiScaler/FG-мод/мод контроллеров скрыты. Нельзя показывать «Контроллеры выключены», когда речь лишь о внешнем модуле, а собственные контроллеры порта работают. NR подписан с указанием OptiScaler.
- Выбранная версия читает свой сохранённый режим настроек; проверка установленного порта не переносится на другую выбранную версию.
- Для уже добавленного архива кнопка обновлений — «Открыть версию»; для ещё не добавленного — «Добавить архив». Переход открывает точную запись по SHA.
- Настройка клавиши OptiScaler скрыта, если этот компонент недоступен. У переводчика убрано неоднозначное «Установлен» и неподтверждаемое подписью утверждение о сохранении Gemini-настроек.

Проверки: publish успешен с прежними CS9057 warning; mod-profile, recommended-settings, version-dates PASS.
