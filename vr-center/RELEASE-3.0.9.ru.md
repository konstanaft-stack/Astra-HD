# VR-центр 3.0.9 — пользовательские и рекомендуемые настройки

По прямому запросу пользователя добавлена компактная плашка «Рекомендуемые настройки» с отдельным переключателем. По умолчанию выключена: настройки принадлежат пользователю. Включение сохраняет точную копию пользовательского UserSettings.json и применяет пресет текущего установленного порта с сохранением языка, аудио, сложности и личных параметров. Выключение возвращает пользовательскую копию. Повторный запуск в пользовательском режиме не восстанавливает старую копию поверх новых изменений.

Для нативных портов режимом пресета управляет VR-центр; first_launch=0 исключает независимое применение стартового пресета. Состояние хранится отдельно для каждой установленной версии в data/game-settings. Перед записью проверяется закрытие игры; файлы меняются с резервом и откатом. При запуске проверяется выбранный режим.

Найден и устранён отдельный дефект portable/Install.ps1: Native-FG принудительно выключал игровую FG для нативных VR-портов при установке/применении комплекта. Installation-Settings теперь сохраняет их UserSettings целиком; flat/legacy-политики оставлены прежними. Это конкретное подтверждённое место перезаписи, а не доказанная единственная причина заявленного пользователем полного сброса при каждом запуске. Обычный Backend Launch не переустанавливал комплект.

Применены явно заказанные настройки: ResolutionScaling=DLSS, DLSS=Balanced, DLSS_NewSharpness=0.25, FrameGeneration=DLSS, DLSSFrameGen=true; прежний множитель x2 сохранён. Рекомендуемые=false, Vortex=false. Содержимое UserSettings после выполнения подготовки пользовательского запуска побайтно не изменилось. Реальная HMD-загрузка/полезная FG и сохранность после неё ещё не подтверждены.

Проверки: recommended-settings.tests.ps1 (Custom default/no overwrite, one-shot flag, preset, personal settings, exact restore, newer custom edits); settings-persistence.tests.ps1 (native FG сохранена при обоих флагах установщика); fg-settings.tests.ps1 PASS. Publish3.0.9 успешен с прежними CS9057 analyzer warnings. Start-Game -CheckOnly и Install -CheckOnly PASS, игру не запускали. Ярлык и открытый процесс используют releases/3.0.9. Резерв Install.ps1 и настроек: audit/settings-persistence-20261010; applied.json содержит итоговые параметры и SHA.

Уточнение взаимодействий: в библиотеке ipower / iPowerTech Beta3 есть CyberpunkVRPort_Interact/init.lua и CyberpunkVRPort_HandLook/*.reds; хеши файлов проверены. В установленной нашей ToFu-сборке этих модулей нет. README iPowerTech прямо описывает palm-ray и touch terminal/elevator/car door (https://github.com/iPowerTech/cyberpunk-vr-port). Текущий ToFu xr_chord_activation=1: R3 + left stick=D-pad, R3+X=recenter, обычный device_click=X. Отсутствие самого наведения/подсказки у лифта пользователь подтвердил отдельно; обычная инструкция навигации его не устраняет. Форк самовольно не переключали, его скрипты отдельно не подмешивали.
