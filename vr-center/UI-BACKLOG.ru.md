Перед проектированием общедоступной версии сравнить существующие менеджеры VR-портов и их пользовательские сценарии, затем проверить наш сценарий с неопытным пользователем. ## 09.10.2026 — навигация через карточки портов (прямое уточнение пользователя)
Статус: записано к доработке; пока не реализовывать в рамках записи.

1. Главная страница остаётся библиотекой игр с карточками: например, Cyberpunk 2077.
2. Нажатие на игру открывает отдельный экран карточек вариантов запуска этой игры, оформленный в том же стиле, что и главная библиотека.
3. Первая карточка — «Плоская игра» (стандартный запуск). Далее — отдельные карточки VR-портов/форков.
4. Нажатие на карточку порта открывает настройки именно этого порта для выбранной игры.
5. Настройки по умолчанию показываются компактно; из них доступен переход в расширенный режим.
6. Версии/сборки относятся к своему порту и выбираются внутри него; не размножать их в самостоятельные карточки на главной странице игр.

Иерархия: Игры → варианты запуска выбранной игры (Плоская игра первой, затем VR-порты) → компактные настройки выбранного порта → расширенные настройки.
Не открывать настройки порта сразу по нажатию на карточку игры, как сделано сейчас. Не подменять промежуточный экран глобальной вкладкой всех портов без контекста игры.
## 09.10.2026 — компактные кнопки состояний и контекст выбранного порта
Статус: записано по прямому уточнению пользователя; сейчас интерфейс не менять.

- Внутри выбранного VR-порта показывать только его компоненты, настройки, версии и действия. Убрать переключатели/списки других портов с этого экрана. Выбор другого порта — через возврат к карточкам игры.
- В расширенном режиме максимально использовать место одного окна: компактная сетка кнопок вместо больших карточек с отдельными надписями, длинными пояснениями и отдельными тумблерами. Показывать только настройки, относящиеся к выбранному порту.
- Название компонента является самой кнопкой. Например, кнопка «DLSS 5»: нажатием на неё включить/отключить компонент; состояние читается по цвету самой кнопки. Не делать рядом ещё один самостоятельный переключатель для того же действия.
- Пользователь предложил зелёный/красный для включено/выключено, но точную палитру и число цветов не фиксировал. Дополнительные состояния при необходимости тоже различимы; цвета имеют единый смысл во всём приложении и соответствуют фактическому состоянию.
- Объяснения убрать с постоянно видимой поверхности в короткую подсказку при наведении: что делает конкретный компонент, например DLSS 5/нейрорендеринг. Не смешивать разные функции под одной ошибочной подписью.
- Подсказки сделать существенно менее прозрачными, предпочтительно со сплошным тёмным фоном и контрастным текстом. Белый текст основного окна не должен просвечивать и сливаться с текстом подсказки. При необходимости скорректировать шрифт. Проверить читаемость поверх плотного текста основного окна.
- На КАЖДОЙ карточке VR-порта на экране выбранной игры нужна собственная кнопка «Проверить обновления» (расположение сверху/снизу карточки допускается). Она проверяет именно этот порт. Отдельная общая страница обновлений не заменяет это действие.
- Уже находясь в конкретном порту, показывать результаты обновлений именно этого порта, без навязывания выбора другого репозитория/порта.

Эти требования дополняют предыдущую иерархию экранов. Это запись будущей доработки, не утверждение о реализации.
