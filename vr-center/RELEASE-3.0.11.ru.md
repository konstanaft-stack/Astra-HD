# VR-центр 3.0.11 — версии и даты

По последнему прямому уточнению: список содержит только локальные версии; строка показывает название и dd.MM.yyyy HH:mm, без «скачано»/«не установлено». Зелёный означает именно подключённую к игре версию (installed.json), красный — другую локальную. Наличие архива не считается подключением. Статусные подписи «Установлен»/«СЕЙЧАС УСТАНОВЛЕНО» убраны с карточек; дата установки показана под названием текущего порта в расширенном виде без отдельного статусного слова.

Время загрузки берётся из проверенных *.download.json по SHA архива, не из времени публикации GitHub. Даты устанавливаются в UTC и показываются в локальной зоне Windows/Samara. Неизвестные старые даты не выдумываются. Времена установок восстанавливаются из receipts/snapshots и сохраняются в data/version-install-times.json. Новые записи сортируются выше старых.

DownloadAndImport/ImportDownloaded возвращают exact focusVersionId по SHA и оригинальной записи каталога. После успеха окно загрузки закрывается, открывается карточка именно добавленной версии. Игра не меняется до Применить; текущий установленный порт остаётся прежним. При выборе другого порта прежний результат проверки файлов не переносится на него.
