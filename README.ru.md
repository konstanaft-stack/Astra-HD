**Cyberpunk 2077 в VR · Активная разработка**

Astra HD — экспериментальное ответвление [dariulone/cyberpunk-vr-port](https://github.com/dariulone/cyberpunk-vr-port). Наша цель — комфортное прохождение игры в VR: согласованная стереокартинка, чёткое изображение и интерфейсы, удобные в шлеме.

> **Стабильного выпуска Astra HD пока нет.** Сейчас публичный репозиторий содержит исходную базу порта и описание проекта. Собственные изменения разрабатываются и проверяются локально; унаследованные файлы исходного проекта ещё не являются проверенной сборкой Astra HD.

## Разработка и проверка

| Направление | Текущее состояние |
| --- | --- |
| Игровой мир в обоих глазах | Проверен в локальных сеансах симулятора OpenXR; расширенная проверка в шлеме остаётся открытой |
| Стерео персонажа в инвентаре | Визуально подтверждено в локальном симуляторе |
| Стерео редактора внешности | Вывод обоих глаз визуально подтверждён в симуляторе OpenXR 15 октября; проверка в физическом шлеме впереди |
| Интеграция генерации кадров NVIDIA | Проверена в отдельных локальных сценариях; производительность, переходы и совместимость ещё проверяются |
| Сохранение настроек | Стартовые сбросы пока не устранены |
| Стабильное прохождение всей игры | Пока не подтверждено |

Сейчас занимаемся стерео редактора персонажа, надёжностью изображения, генерацией кадров и сохранением настроек. Далее — расположение HUD, навигация, выбор оружия и другие взаимодействия в VR.

Результаты симулятора помогают разработке. Комфорт, движение, качество изображения и производительность также должны пройти проверку в физическом шлеме. Инструкции по установке и готовые файлы Astra HD появятся вместе с проверенным выпуском.
